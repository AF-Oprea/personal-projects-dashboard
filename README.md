# AF-Oprea

**Private streams… Public pulse.**

<sub>A living journal of whatever I'm building, breaking, or over-engineering this week.</sub>

---

**What this is**

An auto-refreshed portfolio pulse (~every 15 minutes) — **not** the source code for these projects. Four SVG panels summarize honest roadmap progress, recent coding activity, codebase size, and a live commit feed across personal product streams (RunGuard, Stellami, EASM, Mafia Online, and others). Percentages come from lifecycle roadmaps and measured code changes; this is a calling card, not a product wiki.

| Panel | Shows |
| --- | --- |
| **Pulse** | Overall and per-stream roadmap %, lifecycle chapter bar, code Δ footer |
| **Work calendar** | Lines-of-code change over Δ 30m · Δ 24h · Δ 7d |
| **Worth panel** | Tracked LOC and language mix per stream |
| **Command center** | Live commit stream — when · project · action |
