# AF-Oprea

**Private streams... Public pulse.**

<sub>A living journal of whatever I'm building, breaking, or over-engineering this week.</sub>

</div>

**What this is.** An auto-refreshed portfolio pulse (~every 15 minutes) — **not** the source code for these projects. Three SVG panels snapshot honest roadmap progress, measured codebase size, and a live commit feed. This is a calling card, not a product wiki.

**How the numbers get here.** Roadmap % and chapter bars come from each stream’s lifecycle `roadmap.json`. LOC and languages are counted from local clones. Code Δ in the pulse footer is % LOC over 30m / 24h / 7d / 30d. CXP/UTIL and the worth-panel index are defined on the panel itself. Operators should not invent or hand-edit those figures in this repo — see [docs/PULSE.md](docs/PULSE.md).

**Copy that must match reality.** Stream **CCDPC** (not Courage PC) is **live public** at [ccdpc.af-oprea.ro](https://ccdpc.af-oprea.ro). **Stellami** notes Stripe on the store path when accounts exist. Do not resurrect `courage-pc`.

| Panel | Shows |
| --- | --- |
| **Pulse** | Overall and per-stream roadmap %, six lifecycle chapters, code Δ footer |
| **Worth panel** | Complexity, utility, LOC, index, language mix |
| **Command center** | Live commit stream — when · project · action |
